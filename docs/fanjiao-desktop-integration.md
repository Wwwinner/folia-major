# 饭角桌面接入

<!-- 当前文件记录正式 Electron / Omni 接入的运行方式与验证范围。 -->

2026-09-14：饭角已接入 Folia 的专辑搜索、分集目录、播放队列和歌词页。使用原生 Node.js 实现，不需要 Python、HAR 或数美 SDK。

## 启动与使用

```sh
npm run dev:electron
```

在首页右下的平台切换器选择「饭角」，搜索剧名并打开专辑，通过分集卡片或「查看曲目」列表播放。可用「冬日花火」的「沈楝 早安铃声 5K追剧福利」验证。

### 分区首页

- 推荐页顶部展示官方主横幅，使用同一首页接口提供的图片和专辑跳转信息。横幅居中，左右露出相邻内容，桌面主图最高约 220px；保留图片比例，支持鼠标拖动、触屏滑动、箭头、键盘方向键和分页点，首尾可连续切换，每张停稳后 5 秒自动切换。悬停、键盘聚焦、拖动、离屏或窗口处于后台时暂停。点击进入对应专辑；横幅图片与专辑封面分别存储，未知跳转不透传给界面。
- 饭角首页无需登录，提供「推荐／分类／榜单」导航。推荐按官方音频栏目展示，专辑卡片直接进入已有详情与分集页；榜单支持五个标签切换，首页展示当前榜前三名，「更多」进入完整分页榜单。精品周更使用接口横图，以桌面三列、窄窗两列的 2:1 网格展示全部条目，封面左下角显示播放量；其他专辑栏目按接口下发数量展示完整横向列表，不再截取六部。鼠标可拖动并惯性滑行，触控板与触屏沿用原生横向滚动，纵向滚轮仍滚动首页。拖动松手不触发卡片，后续鼠标点击和键盘激活正常。
- 首页纵向滚动条默认透明隐藏，鼠标靠近右侧滚动条（约 28px 内）或滚动时淡入；滚动结束约一秒且鼠标离开右侧区域后渐隐，支持直接拖动原生滑块，显隐不改变页面宽度。横向栏目和栏目详情隐藏滚动条，保留原生滚轮与触屏滚动。首页支持从封面或空白处上下拖动；手势首次越过阈值后锁定横纵方向，横向交给栏目、纵向交给整页，松手后惯性滑行。「更多」列表也支持纵向拖动，切换页面时停止惯性。
- 新剧速递、「恋爱怎么会和谁谈都一样🌹」、「如果爱忘了💔泪不想落下💦」与「——副本加载完毕——」使用紧凑图文卡片：宽屏三列、中等窗口两列、窄窗单列，左侧约 115×154px 竖封面和播放量，右侧展示剧名、最多两行的首段简介及最新一集，保留既有更多入口和纵向拖动。首页与更多页简介均保留原始换行。
- 分类可组合类别、题材、更新状态、价格和排序，并继续加载下一页。封面失败、空结果和请求失败分别处理，失败可重试。
- 首页「继续收听」读取本机最近未完成的记录，同一专辑只显示最近一集；仅按分集身份补齐标题与封面，不随五秒进度写入重复请求。点击时加载完整专辑队列，再交给已有逐集续播逻辑。
- 首页接口需使用已验证的 App User-Agent；默认 Node UA 虽返回成功，却没有推荐栏目。新目录请求仍经过 Omni、provider、Electron 白名单，仅传归一化专辑与栏目；广告、活动外链和 CV／漫画跳转不作专辑处理。
- 主进程对发现页请求短暂缓存并合并并发请求；首页分页按上游模块总数推进，不能按归一化后的栏目数量或专辑数量计算。
- 推荐首页的归一化首屏另存入按 provider 隔离的 IndexedDB 快照，最长展示 24 小时内的快照，并同时后台刷新；刷新失败保留已有内容。晚到的旧缓存/旧来源响应不能覆盖新结果，只保存首屏分页元数据，不混存后续页、播放地址或授权。
- 投喂榜、追剧榜、人气榜、新品榜、免费榜使用 `/ranking/album`，固定 `tab=2…6`、`time_type=1`，复用 Omni 栏目分页。名次取 `rank`，指标分别取 `feeding`、`liked`、`popularity`、`play`、`play`，不会用播放量替代其他指标或重新排序。投喂、追剧、人气榜的 `total=0` 视为未知总数，继续按实际页长加载，遇到短页、空页或整页重复时停止。投喂「总榜」仅显示占位，切换不发请求；本轮不接入往期榜单和直播榜。
- 13 个普通专辑栏目的「查看更多」均接入独立栏目页：热门速递、精品周更、热播有声、新剧速递使用 `/recommend/major`，其余九个专题使用 `/recommend/special`，主进程将固定栏目标识映射到已核验的 type。页面按接口顺序分页，左侧竖封面显示播放量和预售标签，右侧展示剧名、首段简介与更新集名。进入专辑再返回会保留列表及滚动位置，返回推荐页也恢复原位置及栏目横向位置；播客、CV、榜单和话题跳转仍不作为普通专辑栏目接入。

### 对白字幕模式

- 未来两句提前排好莫奈 waiting 行，不挂载未来文字或可点击目标；雾只在对应句开始前约一秒渐显，远期透明并停止绘制。雾宽由文字排版测量决定，主雾连贯且厚薄不均，边缘在已有光晕留白内少量扩散；随同一字幕行上移，不改变行高、换行或滚动轨迹，也没有独立底部定位，各句保留不同纹理相位。文字到点开始显现，雾先随莫奈行起步再逐渐散开。散雾通常约 0.65 秒完成，短句按自身时长缩短，并随播放时钟暂停和回退；手动回看与减少动态效果时关闭雾层。
- 在歌词样式选择器中选择「对白」，也可通过命令面板切换。对白直接使用莫奈的完整布局、动效和外观参数，窄窗口以文字为主。
- 只显示播放时间已经到达的字幕；回退进度后，之后的台词立即从列表移除。整句按原始开始/结束时间高亮，重叠对白同时高亮，不模拟逐字填色。
- 点击字幕或按 Enter／空格定位到该句并继续播放，沿用现有歌词偏移换算。滚轮和触屏可回看历史，空闲后按莫奈原有逻辑自动跟随；预览宿主禁用点击跳转。
- 长字幕使用莫奈的有限行窗口，播放时仅在句子边界更新；无字幕和第一句开始前有独立空态。字幕前不附加播放图标。
- 当前句自然换行并保留原有换行，按实际排版高度安排间距。恢复莫奈的光晕，以整句同时亮起、结束后淡出，暂停和回退跟随播放时钟；逐字填色与扫光保持关闭。封面样式、频谱、字体缩放等参数与莫奈共用。参数中的「发光强度」可在 0–200% 调整，默认 100%，0% 关闭光晕；自动保存并随外观配置导入导出。

### 独立桌面字幕

- 从「设置 → 桌面端 → 桌面字幕」或托盘「桌面歌词」打开独立透明置顶窗口。只显示当前仍在生效的句子，重叠句同时保留；不显示未来台词、封面、播放控件，也不创建第二个音频播放器。
- 文字沿用 Folia 字体与莫奈整句光晕，支持长句换行。解锁时可拖动窗口，悬停显示设置、锁定和关闭按钮；锁定后鼠标穿透，可从托盘或设置解锁、重置位置。
- 字号 24–64px、发光强度 0–200%，与主播放器分别保存；这两个外观值参与视觉配置导入导出，窗口位置、开启与锁定状态仅本机持久化。主窗口隐藏到托盘时继续显示，重启应用恢复原位置；屏幕变化会把窗口收回可用区域。
- `desktop-lyrics.html` 单独加载轻量字幕入口；主窗口经原有 Electron 播放快照发布时钟，字幕窗口复用对白的重叠时序判断。半秒时钟消息省略未变化的歌词全文，暂停、等待、跳转与倍速事件即时同步；失去时钟后最多外推一秒。

### 收听历史

- 饭角模式顶部「电台」替换为「历史」，与「首页」同级；其他音乐来源保留电台入口。命令面板可搜索「打开收听历史」。
- 以剧为单位呈现最近收听分集，按今天／昨天／更早分组，桌面双列、窄窗口单列。点击封面或剧名进入专辑，点击「分集记录」打开仅含听过分集的右侧栏。
- 历史、首页继续收听和逐集进度共用 `folia_episode_progress_v1`。新记录只额外缓存展示元数据和真实收听时间，不存媒体地址与授权；旧记录分批通过 Omni 补齐，不改变进度或收听日期。已完成分集保留，支持重听。
- 续播先通过 Omni 加载完整专辑队列，再调用既有播放器恢复位置；侧栏的历史子集不会替代播放队列。暂停后退出不会把旧收听时间推到现在。

### 跨设备收听数据同步

- 「存储设置 → 同步服务」中的「同步饭角数据」位于「同步 AI 主题」「同步视觉设置」右侧，点击后直接同步收听记录与续播，无需额外勾选。正片播放偏好仅保存在本机，不再同步；命令面板保留同名同步动作。
- 历史分集侧栏支持删除记录，历史页支持清空饭角历史，均先确认。删除与清空随下次历史同步传播；旧离线设备不会恢复已删除的进度，明确重听可重新记录。
- 同步使用独立本机 journal，保留旧 `folia_episode_progress_v1` 展示缓存。原记录及收听时间平滑迁移；下载不会修改当前音频位置或播放队列。当前会话遇到远端更新时，延后到会话结束再应用。
- 需要更新同步服务端；旧服务显示升级提示，主题与外观同步继续可用。饭角官方 App 历史、账户凭据、媒体授权、播放地址和音频缓存不在同步范围。协议、限制和验证入口见 [饭角同步协议](fanjiao-sync-protocol.md)。

### 逐集进度与正片连续播放

- 播放底栏新增正片跳转图标按钮，仅广播剧显示；开启时高亮，悬停显示说明。分集列表和专辑面板不再显示文字开关。
- 队列始终保留全部分集。正片模式依据 `is_positive=1`（包括小剧场），立即影响上一集、下一集和自动续播的目标，跳过附加内容；关闭后按完整队列逐集跳转。按钮标题、下一集预览和预取使用同一选择规则。手动点播花絮、预告或福利音始终允许，不会删改队列。
- 分集分别记住位置；暂停、跳转、切集和正常退出时立即保存，播放期间每 5 秒保存一次。重新进入未听完的分集会继续播放；实际触发结束事件后标记已听完，再次播放从头开始。
- 分集列表保留接口原顺序，不显示分类和总时长。单集播放量来自接口的 `play` 字段，以向右小三角加数字显示，千用 `k`、万用 `w`（最多一位小数）；缺失时显示「—」。有收听记录时显示「已播放 mm:ss」并提供「从头播放」按钮；专辑信息面板提供最近未听完分集的「继续收听」入口。命令面板也可切换正片跳转、从头播放本集。
- 分集行不再显示「加入播放队列」。面板右上角可切换单列／双列；双列按原顺序一行两集，面板从 320px 平滑展开至 480px（1.5 倍），窄窗口受可用宽度限制。切换保留阅读位置，减少动态效果时直接切换宽度。单双列格子均为 76px，长标题单行省略，播放信息优先同行，窄格内可换行；最后一行允许只有一集。
- 进度按 provider 与分集 ID 区分，当前保存在本机，尚未跨设备同步。记录上限为最近 2000 集；异常断电可能丢失最后约 5 秒。

签名凭据只由 Electron 主进程读取，按顺序选择：

1. 环境变量 `FANJIAO_SIGNATURE_SECRET`。
2. 环境变量 `FANJIAO_SIGNATURE_SECRET_FILE` 指定的本机文件。
3. 开发环境项目根目录的 `.fanjiao.secret`；发行环境 Electron `userData` 目录中的同名文件。

本机开发凭据已准备好。`.fanjiao.secret` 和原始 HAR 均被 Git 忽略；凭据不会进入 renderer、打包源码或示例配置。

饭角清单、音频分片与字幕由 Chromium `net.request` 下载，与其他音乐的 `<audio>`／renderer fetch 共用 `session.defaultSession`。在「设置 → 桌面端 → 代理设置」选择跟随系统、不使用代理或自定义代理；自定义支持无账号密码的 HTTP、HTTPS、SOCKS5 地址，例如 `http://127.0.0.1:7897`。保存后重启 Electron 生效，保存过程中不重置会话或关闭播放连接。该设置用于桌面 Chromium 网络请求，更新检查也遵循它；AI 请求可在下方单独启用，Node API 请求不在该设置范围内。

首次启动时迁移旧 `FANJIAO_MEDIA_PROXY` 或开发目录（发行版为 `userData`）下的 `.fanjiao.proxy.local`，此后以设置页保存的 `NETWORK_PROXY` 为准，旧文件不会覆盖用户选择。无旧配置时默认跟随系统。本机文件仍由 `*.local` 忽略；上游媒体地址继续保留在主进程。配置本地 Clash 端口时须保持该服务运行。

Chromium 适配器只向既有媒体处理层提供状态和字节流，不将上游响应头重建为 WHATWG Headers；饭角字幕的 `Content-Disposition` 可含中文文件名，会使当前 Electron `Session.fetch` 在 ByteString 转换时抛出未捕获异常。`net.request` 避开该问题，同时保留 Chromium 连接/代理、重定向拒绝、取消、完整响应校验和资源上限。目录 API 与 VOD 授权仍由原有 Node transport 处理，媒体下载不再依赖 Undici ProxyAgent。

## 调用与资源边界

```text
Folia 搜索 / 专辑 / 播放队列
  → Omni
  → fanjiaoProvider
  → Electron IPC
  → 原生饭角目录与媒体服务

现有音频节点 + hls.js
  → folia-hls://fanjiao/<集 ID>/<会话 ID>/index.m3u8
  → Electron Chromium 网络栈按需下载，主进程解密并返回分片
```

目录 IPC 只返回白名单 DTO。签名 secret、PlayAuth、临时媒体密钥和上游播放地址保留在主进程。IPC 同时验证主窗口、主 frame 及应用页面来源。

搜索返回专辑，分集才具有 `online:fanjiao:<audio_id>` 播放身份。字幕直接转换成句级 `LyricData`，保留结束时间和重叠行；饭角禁用自动跨音乐平台匹配替代歌词。

播放器把本地清单地址与 MSE blob 分开识别，切源时销毁旧 HLS 实例。饭角采用按集顺序播放，不参与音乐混音、整曲分析或整曲音频缓存。封面缓存仍可复用。

媒体按分片流式加载，每片仍是完整取得后再处理。每个会话最多缓存 8 MiB，最多保留 8 个会话；2 小时未访问的会话由定时清理释放，退出时全部销毁。授权临近本地时限会刷新，分片返回 401/403 时最多刷新重试一次。临时网络错误和 408／429／常见 5xx 最多重试两次，所有尝试共用一次截止时间：音频分片 60 秒，清单与字幕 20 秒；取消、资源大小超限和其他明确拒绝不重试。失败响应体不会混入重试结果。

饭角本地 HLS 分片的首字节等待为 65 秒，与主进程完整下载、解密后才返回响应的 60 秒预算配套。HLS 内建重试之外，播放器每秒检查正在播放的音轨：已有缓冲却 10 秒不推进时，做最多约 0.26 秒的小步修复；缺片（包括首次尚无 metadata）先等待 65 秒再从当前位置重新加载，恢复后仍等待 65 秒才交给现有 Omni 取源恢复，并保留集与位置。正在暂停、结束或已切源的音轨不会自动播放；持续无法完成的 seek 也受此时限约束，新的用户跳转重新获得宽限期。其他 HLS 来源保留原恢复时限。恢复日志仅记录动作、位置和 readyState，不输出媒体地址或授权。

当前集前向缓冲目标保持 60–120 秒，不要求填满后才开始播放。相邻集的取源和首片预热只在当前集已播放、未暂停或跳转且前方至少有 30 秒缓冲时启动；短集已缓冲至结尾也可启动。准备好相邻集授权后再次检查当前缓冲，切集或清理时取消等待，避免首播阶段的后台下载竞争。

## 当前范围

- 支持匿名专辑搜索、详情和分集列表；暂未接入饭角账号、已购内容、收藏或购买。
- 不再用 `is_public`、价格或 `user_has_eligibility` 单独推断可播性。详情返回媒体授权后，实际请求 VOD 和媒体资源；授权缺失、服务端拒绝和网络错误各自保留失败结果，不能转换成“已下架”。授权字符串存在本身不代表媒体请求一定成功。
- 当前 AAC 的 FD 映射为 standard，HQ 映射为 high；用户偏好 lossless/hires 时也不将 AAC 标为无损。
- 分集接口目前返回整份列表，Omni 在本地分页；没有独立总量字段可证明任意大型专辑的完整性。
