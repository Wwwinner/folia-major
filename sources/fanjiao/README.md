# 饭角（桌面端）

饭角是 Folium 2 内置音源，默认停用。配置已有的饭角签名凭据后，从「设置 → 音源」启用。用首页的平台切换器选「饭角」，在原生「推荐」浏览广播剧，点专辑进入原生分集列表；不另设饭角页签。原生搜索选「饭角」后，输入剧名即可搜专辑，不提供单集搜索。饭角不提供账户登录、购买或账户收藏，也不会尝试播放上游没有授权的分集。

「热门速递」「精品周更」在 Bravais 中打开原生集合墙，可在标题栏过滤已加载的专辑或继续加载；Grid 和 TUI 使用专辑列表。点开某部剧才显示分集。

Bravais 推荐墙和专辑歌单墙使用饭角提供的横版、竖版、方版封面，随格子实际比例选图。缺少对应构图时先用方图，再用原封面；不改变磁贴排版。

## 配置

启动 Folia 前设定 `FANJIAO_SIGNATURE_SECRET_FILE`，值为已有凭据文件的绝对路径。也可通过 `FANJIAO_SIGNATURE_SECRET` 提供值；两者都设时后者优先。修改后重启 Folia。只在桌面主进程读取凭据，不随安装包提供，不放进项目或用户设置同步。

```powershell
$env:FANJIAO_SIGNATURE_SECRET_FILE = 'C:\path\to\fanjiao.secret'
npm run dev:electron
```

## 接口与维护

- 匿名目录取自 `api.fanjiao.co/walkman/api`，以 `album_id` / `audio_id` 作为稳定身份。分集按官方顺序分页；`recommendations@1` 向原生推荐提供首页的专辑推荐，不声明私人 FM 或每日推荐。首页若实际返回「热门速递」「精品周更」两个官方模块，会在专辑前给出两个原生专辑播放列表（`playlistContents: 'albums'`，固定 id `featured:popular` / `featured:weekly`），卡片封面取模块中第一个真实子专辑；不预取子专辑详情，也不显示分集数。打开播放列表时才读取 `/walkman/api/recommend/major` 的固定 `type` 1 / 3，只返回专辑，不调用分集或账号接口。原生推荐不提供饭角原来的组合分类和五榜。
- 播放与字幕授权取自分集详情。媒体请求留在主进程，渲染进程的 `hls.js`（固定 `1.7.3`，钉在本目录和根依赖表）只读取本机短时 `folia-mod://` 清单与分片。`playback.external@1` 不经过宿主音频图，不能使用均衡器、宿主频谱、整集音频缓存或音视频导出；重建主窗口会停止原窗口的音轨。
- 在 Folium 2.1 宿主的命令面板运行「继续收听饭角」，从最近一集未完成的进度续播，并按原生播放流程恢复专辑队列。进度和已听完状态仍保存在同一份本机模组数据里，最多 200 集，不读取或同步旧桌面版历史。媒体重开失败可以再试，失败不覆盖已保存的位置。
- 接口变动时先核对 `main/` 中目录 DTO、字幕时间和媒体会话，保持上游地址和授权不经过 RPC。首页播放列表只认 `request_extras.path` + 数字 `type` 匹配的官方模块（`modular_name` 作卡片标题）；major 列表只认固定 id 白名单，打开时只取与请求区间相交的上游 20 条页，跳过损坏专辑并保留上游顺序；`nextOffset` / `hasMore` 按上游原始行数而非去重后数量。生产入口只用 Folium 2 的公开能力。

```sh
npm run sources:build
npm run folium:check -- dist-mods/fanjiao
npm run test:unit -- test/unit/fanjiao
```

桌面冒烟可用隔离配置：从首页的平台切换器选择饭角，确认原生「推荐」能打开剧集专辑且没有私人 FM。也可搜「冬日花火」：用 `120361` 检查首播、暂停、自然续集和约 30 秒处的两条字幕，用 `120484` 检查长集跳转和「继续收听饭角」。在 Grid 与 Bravais 里核对切换平台、打开专辑、返回推荐的原生交互。
